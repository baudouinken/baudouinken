# E-Foncier

This folder contains a minimal Angular 19 project skeleton for the **E-Foncier** MVP.

## Available Scripts

- `npm start` - start the development server
- `npm run build` - build the application for production
- `npm test` - run unit tests

Run `npm install` to install dependencies before using the scripts.

## Fonctionnalités incluses

- Page d'accueil avec navigation
- Liste et détails de titres fonciers
- Recherche par numéro ou nom
- Dépôt de demande avec pièces jointes
- Suivi de dossier avec changement de statut
- Carte des titres fonciers (placeholder)
- Liste de notaires/avocats
